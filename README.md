# 🍙 타베마쇼 3기 지원폼 (Tabemasho Application Form)

동아리 손그림 포스터 감성을 그대로 살려 제작한 **아날로그 스크랩북 & 다이어리 스타일의 인터랙티브 지원폼**입니다.

## ✨ 주요 특징 & 차별화 포인트

1. **접속 즉시 작성 가능한 폼 구조**
   - 불필요한 인트로 랜딩페이지 없이, 접속 즉시 포스터 아이덴티티와 함께 작성할 수 있는 직관적인 폼 UI
2. **인터랙티브 주먹밥(🍙) 프로그레스 바**
   - 지원서 작성 진행도(0%~100%)에 따라 주먹밥 마스코트가 맛있게 완성되는 실시간 게이지
3. **위클리 플래너형 시간표 그리드 (11번 문항)**
   - 평일(월~금) 및 주말(토/일) 시간대를 달력/시간표 앱처럼 클릭 한 번으로 선택
   - '평일 저녁 전체 선택', '주말 오후 전체 선택' 원클릭 퀵 버튼 제공
4. **폴라로이드 즉석 인화 프리뷰 (13번 문항)**
   - 사진을 업로드하면 포스터처럼 마스킹 테이프가 붙은 미니 폴라로이드 사진 액자로 즉시 렌더링
5. **활동 3개 제한 실시간 카운터 (10번 문항)**
   - 3개 초과 선택 시 귀여운 안내 토스트 및 바운스 피드백 제공
6. **일본식 인감 도장(스탬프) 인터랙션**
   - 마지막 필수 확인사항 5개 항목 체크 시 '확인(済)' 도장이 쾅 찍히는 애니메이션
7. **브라우저 자동 임시 저장 (Auto-Save)**
   - 새로고침이나 실수로 창을 닫아도 작성 중이던 내용이 브라우저 로컬 스토리지에 안전하게 보관

## 🚀 실행 및 배포 방법

### 1. 로컬에서 바로 확인하기
- `index.html` 파일을 더블 클릭하여 크롬이나 사파리 브라우저에서 바로 열람할 수 있습니다.
- 또는 터미널에서 간단한 로컬 서버 실행:
  ```bash
  npx serve .
  # 또는
  python3 -m http.server 3000
  ```

### 2. 구글 스프레드시트(Google Sheets) 또는 노션(Notion) 연동 팁
- `assets/app.js` 내의 `initFormSubmit()` 함수에서 `form.addEventListener('submit', ...)` 부분에 **Google Apps Script Web App URL**이나 **Formspree / Zapier / Make Webhook**을 `fetch(url, { method: 'POST', body: JSON.stringify(formData) })` 형태로 한 줄만 연결하시면 지원자 데이터를 구글 시트에 실시간으로 차곡차곡 쌓을 수 있습니다.
